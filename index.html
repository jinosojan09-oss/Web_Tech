10 HTML Tags

1. <html> Tag

The <html> tag is the root element of an HTML document. It contains all the other HTML elements.

2. <head> Tag

The <head> tag contains information about the webpage, such as the title and other settings.

3. <title> Tag

The <title> tag defines the title displayed on the browser tab.

4. <body> Tag

The <body> tag contains all the visible content of a webpage.

5. <h1> Tag

The <h1> tag is used to create the main heading of a webpage.

6. <p> Tag

The <p> tag is used to create paragraphs of text.

7. <a> Tag

The <a> tag is used to create a hyperlink to another webpage.

8. <img> Tag

The <img> tag is used to display images on a webpage.

9. <ul> Tag

The <ul> tag creates an unordered list using bullet points.

10. <br> Tag

The <br> tag is used to insert a line break in the webpage.
